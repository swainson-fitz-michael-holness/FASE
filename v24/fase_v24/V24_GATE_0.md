# FASE v24 Gate 0 — Modal Recursive Closure

## Bedrock claim

Given a licensed mode \(\mathfrak M\) and observations generated by a reusable transition
\(T\in\mathcal L_{\mathrm{fin}}(\mathfrak M)\), an abstraction system should promote a
sequence of finite approximants into the generator \(T\) when this yields stable
extrapolation, invariant preservation, perturbation consistency, and computational
compression.

If no generator in the licensed mode satisfies those criteria, the system may propose a
minimal typed extension \(\mathfrak M^+=\mathfrak M\oplus\{\omega\}\). If no extension
survives the same audits, it must abstain.

## Gate-0 scope

This first artifact uses scalar recursive systems. It intentionally does **not** claim a
domain-general term-graph implementation yet. It tests the promotion logic before the
substrate is generalized to chemistry, molecular biology, lambda calculus, graph rewrites,
or reaction hypergraphs.

### Licensed mode

- affine generators
- quadratic polynomial generators
- cubic polynomial generators

### Meta-alphabet proposals

- square-root affine generator
- sine-affine generator
- Möbius generator

The meta-alphabet is separate from the licensed mode. Selecting one of its families is a
mode-extension event and incurs complexity and promotion thresholds.

## Perturbation audits

### Equivariance

For a declared symmetry \(g\), require the commutative square

\[
\widehat T(gx)\approx g(\widehat T(x)).
\]

### Conjugacy under coordinate change

For any invertible affine coordinate change \(g\), transform the observed transition pairs,
re-infer \(\widehat T_g\), and require

\[
\widehat T_g(gx)\approx g(\widehat T(x)).
\]

This is the general form of applying the same constant operation to the data and to the
model's inference.

### Active perturbation

The lab selects constant translations and scalings that maximize disagreement among the
best current generators. It queries the synthetic environment at those states, appends the
counterfactual transitions, and refits. This tests whether intervention resolves local
surrogate ambiguity.

## Task classes

1. **In-mode recursion:** affine translation and linear scaling. No extension should occur.
2. **Missing-operator recursion:** square-root, sine, and Möbius systems. A minimal operator
   extension should be promoted.
3. **Null process:** an alternating transition with hidden parity. A stationary state-only
   generator is invalid, so the system must abstain.

## Acceptance criteria

A generator is credited only when it satisfies thresholds for:

- one-step validation \(R^2\),
- long-depth rollout NRMSE,
- equivariance error,
- invariant error,
- compression ratio.

A proposed operator must also beat the best licensed generator by a predeclared margin.

## Destroyer clauses

- High one-step prediction alone cannot close the gate.
- A proposed operator that fails long-horizon rollout cannot be promoted.
- A candidate that violates a licensed symmetry cannot be promoted.
- A nonstationary/null process must not receive a false stationary generator.
- The meta-alphabet is not an oracle: every extension pays complexity and must generalize.

## Current limitation

Operator invention is presently constrained to a supplied meta-alphabet. This is an
operator-promotion gate, not yet unrestricted operator genesis. The successor gate should
construct typed rewrite schemas from repeated transition anomalies rather than selecting
from a predefined proposal bank.
